# Project Neptune 

Project Neptune is a joint project between AIAA at UCF and SEDS at UCF.

[Project Neptune website](https://www.ucfprojectneptune.com/)

This repository contains software, engineering models, and supporting documents. 
This is a shared workspace for developing and integrating the vehicle, ground station, and test systems. 

The organization below is the intended structure but may be changed as agreed upon by the affected subteam leads. 

## Repository Organization 

- **Avionics:** Flight computer and power system firmware, tests, design files, and supporting drivers. 
- **Ground Systems:** Telemetry reception, gateway software, operator displays, and launch control software. 
- **Test Systems:** Test Stand and strand burner acquisition software, LabVIEW projects, and testing software. 
- **Simulation:** Shared vehicle flight models and vehicle parameters. Subteam specific simulations are maintained within their respective areas. 
- **Documentation:** System architecture, interface definitions, development guidance. 

## Contributing 

Coordinate changes with the relevant subteam lead. Include setup instructions with your work. Do not upload build outputs, credentials, or restricted material.
